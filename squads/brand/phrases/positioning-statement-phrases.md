# Frases de Declaração de Posicionamento

> Fórmulas e vocabulário para construir declarações de posicionamento estratégico precisas.

## Uso

O posicionamento é a base da estratégia de marca. Use estas fórmulas para articular onde a marca se encaixa no mercado e na mente do consumidor.

## Biblioteca

### Fórmula Clássica (Kotler)
- "Para [público-alvo] que [necessidade], [marca] é a [categoria] que [benefício-chave] porque [razão para acreditar]."

### Fórmula Competitiva
- "Diferente de [concorrente/alternativa], [marca] [diferencial] para [público]."
- "Enquanto [concorrentes] focam em [atributo], nós priorizamos [diferencial]."

### Fórmula de Especialização
- "[Marca]: [categoria] especializada em [nicho] para [público]."
- "A [categoria] feita exclusivamente para quem [comportamento/perfil]."

### Fórmula Aspiracional
- "[Marca] é o que acontece quando [valor] encontra [categoria]."
- "Reimaginamos [categoria] para uma geração que [comportamento]."

### Conectores de Posicionamento
- "...a única que...", "...a primeira a..."
- "...projetada para...", "...construída por..."
- "...na interseção de [A] e [B]..."
- "...onde [atributo] encontra [atributo]..."

### Frases de Moldura Competitiva
- "Não somos [categoria esperada]. Somos [categoria redefinida]."
- "Pense em [referência conhecida], mas para [contexto]."
- "A alternativa a [líder] para quem [diferença de perfil]."

### Vocabulário de Posicionamento
- **Preço**: acessível, premium, justo, democrático, investimento
- **Qualidade**: superior, artesanal, rigoroso, impecável, certificado
- **Velocidade**: ágil, instantâneo, sob demanda, real-time
- **Escopo**: especialista, nichado, vertical, abrangente, completo

### Validação do Posicionamento
1. É verdadeiro e defensável?
2. É relevante para o público?
3. É diferente dos concorrentes?
4. É sustentável a longo prazo?
5. Cabe em uma frase?
