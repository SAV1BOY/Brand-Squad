# Frases de Valores de Marca

> Fórmulas para articular valores de marca de forma viva, acionável e memorável.

## Uso

Valores genéricos ("inovação", "qualidade") são esquecíveis. Use estas fórmulas para transformar valores em declarações vivas que guiam comportamentos reais.

## Biblioteca

### Fórmula: Valor + Comportamento
- "[Valor]: Isso significa que [comportamento concreto]."
- "[Valor] para nós é [ação específica], não apenas [palavra bonita]."
- "Quando dizemos [valor], queremos dizer [exemplo prático]."

### Fórmula: Valor como Regra
- "[Valor]: Se [situação], nós sempre [ação]."
- "[Valor]: Preferimos [escolha difícil] a [escolha fácil]."
- "[Valor]: Mesmo quando custa [sacrifício], mantemos [padrão]."

### Fórmula: Valor como Crença
- "Acreditamos que [crença] — por isso [comportamento]."
- "[Valor] nasce da convicção de que [princípio]."
- "Nosso [valor] não é slogan. É decisão diária."

### Fórmula: Valor em Ação
- "Transparência: Compartilhamos até o que é desconfortável."
- "Excelência: Entregamos acima do esperado, sem exceção."
- "Empatia: Ouvimos antes de propor."
- "Coragem: Dizemos não quando necessário."
- "Simplicidade: Se é complicado, ainda não está pronto."

### Fórmula: Valor como Manifesto Curto
- "[Valor] não é o que fazemos quando é fácil. É o que fazemos quando é difícil."
- "[Valor] é inegociável. O resto, a gente conversa."
- "Se tiver que escolher entre [benefício comercial] e [valor], escolhemos [valor]."

### Anti-Valores (o que NÃO somos)
- "Não confunda [valor real] com [interpretação errada]."
- "Coragem não é imprudência. Simplicidade não é superficialidade."
- "Somos [valor], nunca [distorção do valor]."

### Teste de Valores
1. Alguém seria demitido por violar esse valor?
2. Já custou dinheiro manter esse valor?
3. Ele guia decisões quando ninguém está olhando?
4. É diferente dos valores de 90% das empresas?
