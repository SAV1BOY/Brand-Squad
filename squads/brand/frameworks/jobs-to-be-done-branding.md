# Jobs to Be Done (JTBD) para Branding
> Aplicacao do framework JTBD para posicionar a marca em torno dos "trabalhos" que o consumidor contrata produtos para realizar.

---

## Definicao

Jobs to Be Done (JTBD) e a teoria de Clayton Christensen que propoe que consumidores nao compram produtos — eles "contratam" produtos para realizar um "trabalho" em suas vidas. Aplicado a branding, o JTBD muda o foco de "quem e o consumidor" (demografico) para "o que o consumidor esta tentando realizar" (funcional, emocional e social).

Para branding, a implicacao e poderosa: a marca nao deve se posicionar como "o melhor produto da categoria", mas como "a melhor solucao para o job especifico". Isso expande a visao competitiva (o concorrente pode ser de outra categoria) e refina a comunicacao (falar do job, nao do produto). Um milkshake da manha concorre com banana e barra de cereal, nao com sorvete.

## Quando Usar

- Ao redefinir posicionamento com foco nas necessidades reais do consumidor
- Para identificar oportunidades de inovacao e extensao de marca
- Quando a marca esta presa em guerra de atributos com concorrentes similares
- Para criar comunicacao que ressoa com a motivacao real de compra

## Estrutura / Modelo

```
┌─────────────────────────────────────────────┐
│          JTBD PARA BRANDING                 │
│                                             │
│  ┌─────────────────────────────────────┐    │
│  │          O JOB DO CONSUMIDOR         │   │
│  │  "Quando [situacao], eu quero        │   │
│  │   [motivacao], para que [resultado]" │   │
│  └─────────────────────────────────────┘    │
│                                             │
│  CAMADAS DO JOB:                            │
│  ┌────────────┐                             │
│  │ FUNCIONAL  │ O que precisa ser feito     │
│  ├────────────┤                             │
│  │ EMOCIONAL  │ Como quer se sentir         │
│  ├────────────┤                             │
│  │  SOCIAL    │ Como quer ser percebido     │
│  └────────────┘                             │
│                                             │
│  CONCORRENCIA POR JOB (nao por categoria):  │
│  Job: "Passar o tempo na fila"              │
│  Concorrentes: Instagram, podcast, jornal,  │
│  conversa, candy crush                      │
│                                             │
│  MARCA → posicionar-se como a melhor        │
│  solucao para um job especifico             │
└─────────────────────────────────────────────┘
```

## Como Aplicar (Passo a Passo)

1. **Identifique os jobs**: Entreviste consumidores sobre as circunstancias da ultima vez que "contrataram" seu produto. Foque no contexto e na motivacao, nao no produto.
2. **Mapeie as tres camadas**: Para cada job, descreva a dimensao funcional (o que precisa ser feito), emocional (como quer se sentir) e social (como quer ser visto).
3. **Redefina a concorrencia**: Liste todas as alternativas que o consumidor usa para o mesmo job — incluindo categorias diferentes e "nao consumo".
4. **Posicione a marca no job**: Reformule o posicionamento em torno do job prioritario: "Para quem precisa [job], [marca] e a melhor opcao porque [diferencial no job]."
5. **Comunique o job, nao o produto**: A comunicacao deve mostrar a situacao, o problema e a transformacao — nao atributos tecnicos do produto.

## Exemplos de Aplicacao

**Snickers**: Identificou o job "resolver a fome entre refeicoes quando fico irritado". Posicionou-se nao como "barra de chocolate" (categoria) mas como solucao para o job emocional "voltar a ser eu mesmo". Campanha "Voce nao e voce quando esta com fome" e puro JTBD.

**Uber**: O job nao e "transporte" — e "chegar onde preciso sem estresse, agora". Concorrentes incluem taxi, carro proprio, metro e ate cancelar o compromisso. Uber se posicionou como a solucao de menor friccao para o job "mobilidade sob demanda".

## Erros Comuns

- **Definir jobs muito amplos**: "Ser feliz" nao e um job acionavel. O job deve ser especifico a uma situacao e motivacao concretas.
- **Focar apenas no job funcional**: A dimensao emocional e social frequentemente e o que diferencia marcas na mesma categoria funcional.
- **Confundir job com tarefa**: O job e a motivacao subjacente, nao a atividade. "Furar um buraco" e tarefa; "pendurar um quadro para deixar a casa acolhedora" e o job.

## Integracao com Outros Frameworks

| Framework | Conexao |
|---|---|
| Value Proposition Canvas | O VPC mapeia gains/pains; JTBD define o job subjacente que organiza esses elementos |
| Category Entry Points | CEPs sao as situacoes que ativam o job na mente do consumidor |
| Brand Positioning Statement | O posicionamento deve ser reformulado em torno do job prioritario |
