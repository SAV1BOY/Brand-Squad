# Framework: Modelo de Visão de Marca de Aaker

## Definicao

O Brand Vision Model de David Aaker é um framework que define a identidade aspiracional de uma marca — o que a marca quer representar na mente dos consumidores. Diferente de um simples posicionamento, a Brand Vision é um conjunto articulado de associações que serve como "estrela guia" para todas as decisões de marca. O modelo evoluiu do Brand Identity System original de Aaker (1996) para uma versão mais pragmática em *Aaker on Branding* (2014).

A Brand Vision organiza-se em elementos centrais (core) e elementos estendidos (extended), criando uma identidade de marca rica e multidimensional.

```
+================================================================+
|                     BRAND VISION                                |
|                                                                 |
|   +--------------------------------------------------+         |
|   |              ELEMENTOS CENTRAIS (CORE)           |         |
|   |                                                  |         |
|   |  2-4 dimensões que representam a essência        |         |
|   |  atemporal e imutável da marca                   |         |
|   |                                                  |         |
|   |  - Definem a alma da marca                       |         |
|   |  - Resistem a mudanças de mercado/produto        |         |
|   |  - São verdadeiros em qualquer geografia         |         |
|   +--------------------------------------------------+         |
|                                                                 |
|   +--------------------------------------------------+         |
|   |           ELEMENTOS ESTENDIDOS (EXTENDED)        |         |
|   |                                                  |         |
|   |  6-12 dimensões que completam a identidade       |         |
|   |  e fornecem textura e direção                    |         |
|   |                                                  |         |
|   |  - Adicionam nuance e diferenciação              |         |
|   |  - Podem variar por mercado ou contexto          |         |
|   |  - Guiam execução tática                         |         |
|   +--------------------------------------------------+         |
|                                                                 |
+================================================================+
```

### As 12 Dimensões Possíveis da Brand Vision

```
+---------------------+-------------------------------------------+
| PERSPECTIVA         | DIMENSÕES                                 |
+---------------------+-------------------------------------------+
| Marca como Produto  | 1. Escopo do produto                      |
|                     | 2. Atributos do produto                   |
|                     | 3. Qualidade/valor                        |
|                     | 4. Usos/aplicações                        |
|                     | 5. Usuários típicos                       |
|                     | 6. País de origem                         |
+---------------------+-------------------------------------------+
| Marca como          | 7. Atributos organizacionais              |
| Organização         |    (inovação, confiança, consciência      |
|                     |    social)                                |
|                     | 8. Local vs. Global                       |
+---------------------+-------------------------------------------+
| Marca como Pessoa   | 9. Personalidade da marca                 |
|                     | 10. Relacionamento marca-cliente          |
+---------------------+-------------------------------------------+
| Marca como Símbolo  | 11. Imagética visual / metáforas          |
|                     | 12. Herança / tradição da marca           |
+---------------------+-------------------------------------------+
```

---

## Quando Usar

- Na **construção de marca** de uma nova empresa, produto ou serviço
- Em processos de **rebranding** ou **revitalização** de marca
- Quando a marca precisa de uma **definição estratégica clara** que vá além de um simples posicionamento
- Como base para desenvolvimento de **identidade verbal e visual**
- Para alinhar **stakeholders internos** em torno de uma visão compartilhada da marca
- Como input para **briefings criativos** de campanhas, conteúdo e experiência

## Estrutura / Modelo

### Framework Completo com Proposta de Valor

```
                    BRAND VISION
                         |
          +--------------+--------------+
          |                             |
    CORE ELEMENTS                EXTENDED ELEMENTS
    (Essência)                   (Textura)
          |                             |
          +--------------+--------------+
                         |
                  PROPOSTA DE VALOR
          +--------------+--------------+
          |              |              |
    Benefícios      Benefícios     Benefícios de
    Funcionais      Emocionais     Auto-expressão
          |              |              |
          +--------------+--------------+
                         |
              CREDIBILIDADE / REASON TO BELIEVE
                         |
                RELACIONAMENTO MARCA-CLIENTE
```

### Os Três Tipos de Benefício

1. **Funcionais**: o que a marca faz pelo cliente (utilidade, performance, economia)
2. **Emocionais**: como o cliente se sente ao usar/comprar a marca (segurança, confiança, prazer)
3. **Auto-expressão**: o que a marca diz sobre quem o cliente é (identidade, status, valores)

## Como Aplicar (Passo a Passo)

### Passo 1: Pesquisa de Base
1. Analisar o cliente: segmentos, necessidades, motivações, jornada de compra
2. Analisar a concorrência: como cada concorrente se posiciona nas 12 dimensões
3. Auto-análise: forças reais da marca, herança, cultura, capacidades
4. Análise de tendências: para onde o mercado está indo

### Passo 2: Explorar as 12 Dimensões
1. Para cada uma das 12 dimensões, brainstormar possíveis associações para a marca
2. Avaliar cada associação em três critérios: (a) ressoa com o cliente? (b) diferencia dos concorrentes? (c) é verdadeira para a marca?
3. Eliminar associações que falham em qualquer critério

### Passo 3: Separar Core e Extended
1. Selecionar 2-4 associações que são absolutamente centrais e atemporais — estes são os core elements
2. Selecionar 6-12 associações que complementam e enriquecem — estes são os extended elements
3. Regra: se removido, um core element desnaturaria a marca; um extended element a empobreceria mas não a descaracterizaria

### Passo 4: Articular a Proposta de Valor
1. Definir os benefícios funcionais (o que entrega)
2. Definir os benefícios emocionais (como faz sentir)
3. Definir os benefícios de auto-expressão (o que diz sobre quem sou)
4. Integrar em uma proposta de valor coesa

### Passo 5: Definir Credibilidade e Relacionamento
1. Listar as razões para crer (provas, evidências, capacidades que sustentam a proposta)
2. Definir o tipo de relacionamento que a marca busca com o cliente (mentor, amigo, parceiro, etc.)
3. Documentar tudo em um Brand Vision Document

### Passo 6: Validação e Ativação
1. Testar a Brand Vision com stakeholders internos — faz sentido? Inspira?
2. Testar com representantes do público-alvo — ressoa? É crível?
3. Traduzir em guidelines práticas para equipes de comunicação, produto e experiência

## Exemplos de Aplicacao

### Exemplo: Marca de Tecnologia Educacional

**Core Elements:**
- Democratização do conhecimento (marca como organização)
- Empoderamento pessoal (marca como pessoa — personalidade)

**Extended Elements:**
- Produto: plataforma de aprendizado adaptativo, conteúdo de alta qualidade
- Organização: orientada por dados, socialmente consciente
- Pessoa: acolhedora, curiosa, exigente sem ser excludente
- Símbolo: a "jornada de descoberta", metáfora visual de caminhos que se abrem

**Proposta de Valor:**
- Funcional: aprenda no seu ritmo, com conteúdo atualizado
- Emocional: sinta-se capaz, confiante, em evolução
- Auto-expressão: sou alguém que investe em si mesmo

## Erros Comuns

1. **Identidade aspiracional sem base real**: a Brand Vision deve equilibrar aspiração com verdade — não pode ser ficção
2. **Muitos core elements**: se tudo é core, nada é core — máximo de 4 elementos centrais
3. **Confundir Brand Vision com tagline**: a Vision é um documento estratégico interno, não uma frase de campanha
4. **Ignorar a perspectiva do consumidor**: a Vision deve ressoar com o público, não apenas refletir ambições internas
5. **Criar e arquivar**: a Brand Vision deve ser um documento vivo, consultado em cada decisão de marca
6. **Copiar a Vision do concorrente**: se a sua Brand Vision poderia pertencer a outra empresa, não é sua

## Integracao com Outros Frameworks

- **Keller CBBE**: a Brand Vision alimenta os blocos de Significado (desempenho e imagens) da pirâmide
- **Aaker Brand Personality Scale**: a dimensão "marca como pessoa" se aprofunda com a escala de personalidade
- **Aaker Brand Architecture**: cada marca no portfólio deve ter sua Brand Vision articulada
- **12 Arquétipos**: o arquétipo informa a dimensão de personalidade dentro da Brand Vision
- **Neumeier (Onlyness)**: o onlyness statement pode derivar dos core elements da Brand Vision
- **Miller (StoryBrand)**: a proposta de valor e o relacionamento marca-cliente alimentam a narrativa StoryBrand
