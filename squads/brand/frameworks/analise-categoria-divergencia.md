# Analise de Categoria por Divergencia (Al Ries)
> Framework para analisar como categorias se dividem e criar oportunidades de lideranca em novas categorias.

---

## Definicao

A Analise de Categoria por Divergencia e baseada no principio central de Al Ries: categorias nao convergem — elas divergem. Assim como especies na biologia evolucionaria, categorias de mercado se dividem ao longo do tempo, criando novas subcategorias. A marca que identifica e lidera uma nova subcategoria emergente captura desproporcionalmente o valor gerado.

Este framework e o oposto da visao de "convergencia tecnologica" que domina o pensamento corporativo. Ries argumenta que o computador nao se fundiu com a TV, o celular nao substituiu a camera dedicada para profissionais, e cada divergencia criou oportunidades para novas marcas liderarem.

O principio estrategico: nao tente ser o melhor em uma categoria existente — crie ou lidere uma nova subcategoria divergente.

---

## Quando Usar

- Planejamento estrategico de longo prazo (3-10 anos)
- Identificacao de oportunidades de nova marca/submarca
- Defesa contra disrupcao por novos entrantes
- Decisoes de portfolio de marcas (quando criar nova marca vs estender)
- Analise competitiva de evolucao de categoria

## Estrutura / Modelo

```
ARVORE DE DIVERGENCIA DE CATEGORIA

              [CATEGORIA ORIGINAL]
                     │
          ┌──────────┼──────────┐
          │          │          │
     [Sub-cat A] [Sub-cat B] [Sub-cat C]
          │                     │
     ┌────┴────┐          ┌────┴────┐
     │         │          │         │
  [Sub-A1] [Sub-A2]   [Sub-C1] [Sub-C2]
                          │
                     ┌────┴────┐
                     │         │
                  [C1-alfa] [C1-beta]

  Cada bifurcacao = oportunidade para nova marca lider
```

### Mapa de Sinais de Divergencia

```
  SINAL                    │ INTENSIDADE │ ACAO
  ─────────────────────────┼─────────────┼─────────────────────
  Consumidores pedem       │ Alta        │ Criar subcategoria
  versao "so para X"       │             │ dedicada
                           │             │
  Segmento premium cresce  │ Media-Alta  │ Marca premium
  mais que mainstream      │             │ separada
                           │             │
  Tecnologia nova habilita │ Media       │ Monitorar e preparar
  uso diferente            │             │ lancamento
                           │             │
  Regulacao cria segmento  │ Alta        │ Primeira marca no
  distinto                 │             │ segmento regulado
                           │             │
  Nicho cultural se forma  │ Media       │ Marca de nicho
  com identidade propria   │             │ autenticamente posicionada
```

## Como Aplicar (Passo a Passo)

### Passo 1: Mapear Arvore Historica
Reconstrua como a categoria atual se formou. Quais divergencias ja ocorreram? Quais marcas lideraram cada bifurcacao?

### Passo 2: Identificar Sinais de Divergencia Atual
Busque sinais: segmentos crescendo mais rapido que a media, consumidores hackeando produtos para usos nao previstos, insatisfacao especifica de subgrupos, novas tecnologias habilitadoras.

### Passo 3: Projetar Divergencias Futuras
Com base nos sinais, projete 3-5 possiveis bifurcacoes nos proximos 5-10 anos. Classifique por probabilidade e timing.

### Passo 4: Avaliar Potencial de Lideranca
Para cada divergencia projetada, avalie: a empresa tem competencia para liderar? Ha first-mover advantage real? O mercado potencial justifica investimento?

### Passo 5: Decidir Estrategia de Marca
Principio Ries: nova categoria = nova marca. Nao estenda a marca existente para a nova subcategoria. Crie uma marca dedicada que possa "ser dona" da nova categoria.

### Passo 6: Executar e Nomear a Categoria
Defina o nome da nova categoria (quem nomeia, lidera). Posicione a nova marca como a original/autentica da categoria. Eduque o mercado sobre POR QUE a nova categoria existe.

## Exemplos de Aplicacao

### Exemplo 1: Cerveja → Cerveja Artesanal
Divergencia classica. A categoria "cerveja" divergiu em industrial e artesanal. Marcas como Lagunitas e Stone lideraram a subcategoria. Grandes cervejarias que tentaram com extensao de marca (Budweiser "craft") falharam — precisaram comprar marcas nativas.

### Exemplo 2: Taxi → Ride-sharing
A categoria "transporte individual" divergiu. Uber nao tentou ser um "taxi melhor" — criou a categoria ride-sharing. O nome novo da categoria foi essencial para a percepcao de inovacao.

### Exemplo 3: Leite → Leite Vegetal
Divergencia por mudanca cultural (veganismo, intolerancia). Alpro e Oatly lideraram a subcategoria. Marcas de leite tradicionais que lancaram versoes vegetais tiveram pouca credibilidade.

## Erros Comuns

1. **Acreditar em convergencia:** O erro mais frequente e achar que categorias vao se fundir ("o celular vai substituir tudo"). Na pratica, divergencia cria mais oportunidades que convergencia.
2. **Estender marca existente para nova categoria:** Ries e enfatico: extensao de marca enfraquece a marca original e nao lidera a nova categoria.
3. **Criar subcategoria cedo demais:** Divergencia prematura nao encontra mercado. O timing e tao critico quanto a identificacao.
4. **Nao nomear a categoria:** Se voce nao da nome a nova categoria, outra marca dara — e capturara a lideranca.
5. **Confundir tendencia passageira com divergencia real:** Nem toda moda e divergencia. Divergencias reais tem fundamento estrutural (tecnologia, demografia, regulacao).

|-----------|---------|---------------|
| Auditoria de Foco (Ries) | Complementar | Foco garante que a marca nao se disperse ao explorar divergencias |
