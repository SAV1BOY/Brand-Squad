# Matriz de Decisão de Marca

> Ferramenta para avaliar e comparar opções de branding de forma objetiva e estruturada.

## Como Usar

1. Defina as opções a comparar (nomes, taglines, posicionamentos, etc.)
2. Selecione critérios relevantes da lista abaixo
3. Atribua pesos aos critérios (total = 100%)
4. Pontue cada opção de 1-5 em cada critério
5. Calcule: Nota = Soma(Peso x Pontuação)

## Regras de Uso
1. Mínimo 3 avaliadores independentes
2. Defina critérios e pesos ANTES de ver as opções
3. Pontue individualmente, depois compare
4. Matriz informa a decisão — não substitui julgamento
5. Documente a decisão e os motivos para referência futura
