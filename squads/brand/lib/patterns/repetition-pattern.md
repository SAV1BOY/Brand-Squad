# Padrão: Repetição

> Usar repetição estratégica de elementos-chave para fixar a marca na memória do público.

## Quando Usar

- Construção de awareness para marca nova
- Fixação de novo posicionamento após rebrand
- Lançamento de tagline ou campanha-chave
- Qualquer momento em que memorabilidade é prioridade

## Como Aplicar

### Princípio Central
As pessoas precisam de múltiplas exposições para lembrar. Repetição não é preguiça — é estratégia. O que parece repetitivo para a marca é novidade para a maioria do público.

### O Que Repetir
1. **Ativos Distintivos**: Logo, cores, som, personagem — sempre presentes
2. **Mensagem Central**: Mesma promessa, diferentes execuções
3. **Estrutura Narrativa**: Mesmo formato de storytelling
4. **Rituais**: Comportamentos associados à marca
5. **Vocabulário**: Termos proprietários usados consistentemente

### Regra da Repetição Eficaz
- Repita o CONCEITO, varie a EXECUÇÃO
- Mesmo insight → diferentes histórias
- Mesma promessa → diferentes provas
- Mesmo ativo → diferentes contextos

### Frequência
- **Regra de 7**: Público precisa ver a mensagem 7+ vezes
- **Decay**: Sem reforço, a memória decai em semanas
- **Always-on**: Presença contínua > rajadas intensas

## Exemplos

- **Mastercard**: "Não tem preço" repetido por 25+ anos
- **L'Oréal**: "Porque você vale muito" — décadas
- **Havaianas**: "Todo mundo usa" — tema recorrente

### Anti-padrão: Síndrome da Novidade
- Trocar campanha antes de ela se fixar
- Redesenhar identidade por tédio interno
- Abandonar tagline porque "a equipe cansou"
- Lembre: a equipe viu 1000x, o público viu 3x
