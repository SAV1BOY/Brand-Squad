# Padrão: Simplicidade

> Reduzir complexidade para aumentar clareza, memorabilidade e ação na comunicação de marca.

## Quando Usar

- Marca com mensagem complexa que precisa ser acessível
- Lançamento de produto com muitas features
- Públicos não-técnicos ou com atenção limitada
- Rebranding que precisa simplificar posicionamento legado

## Como Aplicar

### Princípio Central
Elimine tudo que não contribui para a mensagem principal. Se um elemento pode ser removido sem perda de significado, remova.

### Regras Práticas
1. **Uma mensagem por peça**: Cada touchpoint comunica UMA coisa
2. **Vocabulário simples**: Se existe uma palavra mais curta, use-a
3. **Estrutura clara**: Hierarquia visual e textual óbvia
4. **Teste do elevador**: Se não cabe em 10 segundos, simplifique
5. **Corte pela metade**: Escreva, depois corte 50% das palavras

### Aplicação por Touchpoint
- **Tagline**: Máximo 5 palavras
- **Homepage hero**: 1 headline + 1 sub + 1 CTA
- **Email**: 1 objetivo por email
- **Post social**: 1 ideia por post
- **Apresentação**: 1 conceito por slide

## Exemplos

- **Apple**: Nomes simples (iPhone, iPad), copy minimalista
- **Google**: Homepage com apenas um campo de busca
- **Nubank**: Linguagem bancária traduzida para linguagem humana

### Anti-padrão
- Poluição visual com excesso de elementos
- Copy longo quando curto resolve
- Múltiplos CTAs competindo por atenção
- Jargão técnico sem tradução
