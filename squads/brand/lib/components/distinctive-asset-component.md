# Componente: Ativo Distintivo

> Elementos sensoriais que identificam a marca sem necessidade do nome — segundo Byron Sharp.

## Estrutura

```
Ativo: [Descrição do elemento]
Tipo: [Visual / Sonoro / Verbal / Tátil / Olfativo]
Força: [Fame (conhecimento) + Uniqueness (exclusividade)]
Uso Obrigatório: [Contextos onde deve aparecer]
Proteção: [Registro / Trademark / Guideline]
```

## Como Usar

1. Audite ativos atuais usando a grade Fame x Uniqueness
2. Priorize investimento nos ativos com alto potencial
3. Use consistentemente em TODOS os touchpoints
4. Nunca altere ativos fortes sem pesquisa prévia
5. Meça reconhecimento periodicamente

## Exemplo

```
Ativo: Cor roxa (#6B2FA0) como cor primária de marca
Tipo: Visual
Força: Alta unicidade na categoria (nenhum concorrente usa roxo)
Uso Obrigatório: Logo, app, embalagem, ponto de venda
Proteção: Registrada como marca cor na categoria
```

## Variações

### Ativos Visuais
- Logo/símbolo, cor(es) de marca, tipografia proprietária
- Personagem/mascote, padrão gráfico, formato de embalagem
- Estilo fotográfico, ícones proprietários

### Ativos Sonoros
- Jingle, sound logo, voz institucional
- Trilha sonora característica, som de produto

### Ativos Verbais
- Tagline, expressão proprietária, tom de voz único
- Vocabulário exclusivo, naming de features

### Regra de Consistência
- Ativos distintivos precisam de ANOS para se consolidar
- Não mude por tendência — mude apenas com evidência
- Consistência > Criatividade quando o assunto é reconhecimento
