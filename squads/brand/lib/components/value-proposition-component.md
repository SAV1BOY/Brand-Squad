# Componente: Proposta de Valor

> Declaração clara de por que o cliente deve escolher sua marca em vez das alternativas.

## Estrutura

```
Para: [Público-alvo específico]
Que precisa de: [Necessidade ou job-to-be-done]
Nós oferecemos: [Produto/serviço + categoria]
Que entrega: [Benefício principal]
Diferente de: [Alternativas/concorrentes]
Porque: [Razão para acreditar / diferencial]
```

## Como Usar

1. Uma proposta de valor por segmento de público
2. Benefício principal = o mais importante, não todos
3. Deve ser testável — pergunte ao público se é verdade
4. Evolui conforme o mercado muda
5. Base para headlines, pitches e posicionamento

## Exemplo

```
Para: Designers freelancers no Brasil
Que precisam de: Portfólio online profissional sem custo alto
Nós oferecemos: Plataforma de criação de portfólios
Que entrega: Sites bonitos prontos em 15 minutos
Diferente de: Construtores genéricos que exigem customização pesada
Porque: Templates feitos por designers, para designers
```

## Variações

### Canvas de Proposta de Valor (Osterwalder)
- **Perfil do Cliente**: Jobs, Dores, Ganhos
- **Mapa de Valor**: Produtos, Analgésicos, Criadores de Ganho
- **Fit**: Onde mapa de valor resolve perfil do cliente

### Proposta de Valor por Camada
- **Funcional**: O que faz (feature → benefício)
- **Emocional**: Como faz sentir (conexão)
- **Social**: O que diz sobre o cliente (identidade)

### Teste Rápido
- O cliente diria "isso é para mim" em 5 segundos?
- É diferente do que o concorrente comunica?
- Tem prova concreta?
