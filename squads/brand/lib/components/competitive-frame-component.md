# Componente: Moldura Competitiva

> Define a categoria na qual a marca compete e como ela enquadra o cenário competitivo.

## Estrutura

```
Categoria Declarada: [Em que categoria a marca se posiciona]
Concorrentes Diretos: [Marcas na mesma categoria]
Concorrentes Indiretos: [Alternativas e substitutos]
Ponto de Paridade: [O que devemos ter igual ao mercado]
Ponto de Diferença: [O que nos separa — exclusivo]
Reframe: [Como redefinimos a categoria a nosso favor]
```

## Como Usar

1. A escolha da categoria determina com quem você compete
2. Pontos de paridade são pré-requisitos — sem eles, não entra no consideration set
3. Pontos de diferença são sua vantagem competitiva
4. Reframe é a estratégia avançada de mudar as regras do jogo

## Exemplo

```
Categoria Declarada: Plataforma de produtividade para times remotos
Concorrentes Diretos: Notion, Monday, Asana
Concorrentes Indiretos: Planilhas, email, WhatsApp
Pontos de Paridade: Gestão de tarefas, colaboração, integrações
Pontos de Diferença: Automação nativa com IA + interface 100% em PT-BR
Reframe: "Não é mais uma ferramenta de projetos. É o sistema operacional do seu time."
```

## Variações

### Frame de Categoria Nova
- Quando você cria uma categoria inexistente
- Defina: nome, regras, critérios de sucesso
- Ex: "CRM conversacional" em vez de "chatbot"

### Frame de Substituição
- "Substitua [solução atual] por [marca]"
- Foco em migração e custo de troca

### Frame de Nicho
- Subnicho dentro de categoria existente
- Ex: "O CRM feito exclusivamente para clínicas"
