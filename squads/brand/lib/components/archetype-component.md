# Componente: Arquétipo de Marca

> Sistema de personalidade baseado nos 12 arquétipos junguianos aplicados a branding.

## Estrutura

```
Arquétipo Primário: [1 dos 12 arquétipos]
Arquétipo Secundário: [1 complementar — opcional]
Motivação Central: [Desejo humano fundamental]
Medo Central: [O que a marca ajuda a evitar]
Voz: [Como a marca fala]
Comportamento: [Como a marca age]
Palavras-Chave: [5-10 palavras do vocabulário]
```

## Como Usar

1. Identifique o arquétipo através de workshops ou análise cultural
2. Primário = 70% da comunicação; Secundário = 30%
3. Use para guiar tom de voz, visual e decisões de conteúdo
4. Não mude o arquétipo — evolua dentro dele

## Exemplo

```
Arquétipo Primário: Explorador
Arquétipo Secundário: Sábio
Motivação: Liberdade para descobrir e entender o mundo
Medo: Limitação, estagnação, superficialidade
Voz: Curiosa, inspiradora, inteligente sem ser pedante
Comportamento: Desafia convenções, busca novos caminhos
Palavras-Chave: Descobrir, caminho, fronteira, conhecimento, liberdade
```

## Variações

### Os 12 Arquétipos (Resumo)
- **Inocente**: Otimismo, simplicidade, felicidade
- **Explorador**: Liberdade, descoberta, aventura
- **Sábio**: Conhecimento, verdade, compreensão
- **Herói**: Coragem, maestria, superação
- **Fora-da-Lei**: Revolução, liberdade, ruptura
- **Mago**: Transformação, visão, experiência
- **Cara Comum**: Pertencimento, autenticidade, conexão
- **Amante**: Paixão, beleza, intimidade
- **Bobo da Corte**: Alegria, diversão, leveza
- **Cuidador**: Serviço, proteção, generosidade
- **Criador**: Inovação, expressão, imaginação
- **Governante**: Controle, estabilidade, excelência

### Combinações Comuns
- Herói + Explorador = Aventura com propósito
- Sábio + Cuidador = Educação com empatia
- Criador + Fora-da-Lei = Inovação disruptiva
- Governante + Mago = Liderança transformadora
