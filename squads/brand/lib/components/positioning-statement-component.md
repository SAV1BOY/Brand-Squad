# Componente: Declaração de Posicionamento

> Bloco estrutural que define onde a marca se encaixa no mercado e na mente do consumidor.

## Estrutura

```
Para [público-alvo]
Que [necessidade ou oportunidade]
[Marca] é a [categoria/moldura competitiva]
Que [benefício-chave / promessa]
Porque [razão para acreditar / prova]
```

## Como Usar

1. Preencha cada campo com dados reais (não aspiracionais)
2. Valide: cada campo é verdadeiro e verificável?
3. Teste internamente: a equipe entende e concorda?
4. Use como base para toda comunicação — não publique literalmente

## Exemplo

```
Para pequenas empresas brasileiras
Que precisam de presença digital profissional sem complexidade
[Marca] é a plataforma de sites
Que entrega resultado visual em minutos, sem código
Porque 50.000 empresas já criaram seus sites conosco em menos de 1 hora
```

## Variações

### Posicionamento Competitivo
- Adicione: "Diferente de [alternativa], que [limitação]..."
- Use quando a comparação é inevitável no mercado

### Posicionamento Aspiracional
- Substitua "é" por "será" — para marcas em transição
- Inclua timeline: "Até [data], seremos reconhecidos como..."

### Posicionamento por Ocasião
- "Quando [situação], [marca] é a escolha de [público]"
- Útil para marcas com múltiplos contextos de uso

### Posicionamento Interno vs Externo
- **Interno**: Versão completa com RTBs e dados
- **Externo**: Versão simplificada, foco no benefício
