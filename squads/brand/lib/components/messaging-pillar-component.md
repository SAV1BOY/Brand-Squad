# Componente: Pilar de Mensagem

> Bloco temático que sustenta a comunicação da marca, organizando mensagens por tema estratégico.

## Estrutura

```
Pilar: [Nome do pilar — 1-3 palavras]
Mensagem-chave: [Frase principal que resume o pilar]
Submensagens: [2-3 desdobramentos]
Prova: [Evidências que sustentam]
Tom: [Tom específico deste pilar]
Público prioritário: [Segmento mais relevante]
```

## Como Usar

1. Defina 3-5 pilares que cobrem todo o universo da marca
2. Cada pilar deve ser independente mas complementar
3. Toda comunicação deve se encaixar em pelo menos 1 pilar
4. Revise pilares anualmente ou em mudanças estratégicas

## Exemplo

```
Pilar: Simplicidade Inteligente
Mensagem-chave: "Tecnologia complexa, experiência simples"
Submensagens:
  - "Configuração em 3 passos"
  - "Sem manual, sem treinamento"
  - "Funciona como você espera"
Prova: 92% dos usuários completam setup sozinhos
Tom: Confiante e acolhedor
Público prioritário: Empreendedores sem equipe técnica
```

## Variações

### 3 Pilares (Mínimo Recomendado)
- Pilar Funcional: O que entregamos
- Pilar Emocional: Como fazemos sentir
- Pilar Social: O impacto maior

### 5 Pilares (Máximo Recomendado)
- Funcional + Emocional + Social + Cultural + Aspiracional

### Pilares por Público
- Mesmo tema, mensagens adaptadas por segmento
- Ex: "Simplicidade" para dev = autonomia; para CEO = economia

### Matriz Pilar x Canal
- Cada canal prioriza 1-2 pilares
- Evita mensagens conflitantes entre canais
