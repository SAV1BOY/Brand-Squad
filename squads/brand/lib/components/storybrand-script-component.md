# Componente: Script StoryBrand

> Framework narrativo baseado em Donald Miller para posicionar o cliente como herói e a marca como guia.

## Estrutura

```
1. Personagem: [Quem é o cliente — perfil e desejo]
2. Problema: [Externo, interno e filosófico]
3. Guia: [A marca — com empatia e autoridade]
4. Plano: [Passos claros para o cliente seguir]
5. Chamada à Ação: [Direta e transitória]
6. Sucesso: [Como é a vida após a solução]
7. Fracasso: [O que acontece sem a solução]
```

## Como Usar

1. Preencha cada seção focando no cliente, não na marca
2. O herói é o CLIENTE, nunca a marca
3. A marca é o GUIA — com empatia ("entendemos") e autoridade ("sabemos como")
4. Use para websites, pitches, vídeos institucionais e vendas

## Exemplo

```
Personagem: Dono de e-commerce que quer vender mais
Problema Externo: Tráfego caro e conversão baixa
Problema Interno: Sente que está desperdiçando dinheiro
Problema Filosófico: Empreendedores merecem ferramentas justas
Guia: [Marca] — 8 anos otimizando conversão (autoridade) + "sabemos como é frustrante" (empatia)
Plano: 1) Diagnóstico grátis 2) Implementação em 7 dias 3) Resultado em 30 dias
CTA Direta: "Agende seu diagnóstico"
CTA Transitória: "Baixe o guia de conversão"
Sucesso: ROI positivo, confiança, escala sustentável
Fracasso: Continuar queimando verba sem resultado
```

## Variações

### Script para Website (Homepage)
- Header = Personagem + Desejo + CTA
- Seção 2 = Problema + Empatia
- Seção 3 = Plano (3 passos)
- Seção 4 = Sucesso + Prova social

### Script para Email Marketing
- Assunto = Problema interno (dor)
- Corpo = Guia + Plano + CTA

### Script para Pitch de Vendas
- Abertura = Problema filosófico
- Meio = Autoridade + Plano
- Fechamento = Sucesso vs Fracasso + CTA
