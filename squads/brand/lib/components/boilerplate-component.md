# Componente: Boilerplate

> Parágrafo institucional padronizado que descreve a marca de forma consistente em todos os materiais.

## Estrutura

```
Frase 1: [Marca] é [definição — o que faz + para quem]
Frase 2: [Missão ou propósito resumido]
Frase 3: [Prova de credibilidade — números, clientes, prêmios]
Frase 4: [Informação adicional — site, localização, fundação]
```

## Como Usar

1. Mantenha versões em 3 tamanhos: micro, padrão, expandido
2. Atualize dados quantitativos trimestralmente
3. Use em press releases, propostas, rodapé de apresentações
4. Toda aparição pública da marca usa o mesmo boilerplate
5. Traduza para EN se a marca atua internacionalmente

## Exemplo

```
[Micro - 1 linha]
A TechFlow simplifica a gestão financeira de PMEs brasileiras.

[Padrão - 4 linhas]
A TechFlow é uma plataforma de gestão financeira que simplifica
a rotina de pequenas e médias empresas brasileiras. Fundada em 2020,
a empresa atende mais de 5.000 negócios em todos os estados do Brasil.
Saiba mais em techflow.com.br.

[Expandido - 6 linhas]
A TechFlow é uma plataforma de gestão financeira criada para
simplificar a rotina de pequenas e médias empresas. Com a missão
de democratizar o acesso a ferramentas financeiras profissionais,
atende mais de 5.000 negócios desde 2020. Premiada como Melhor
Fintech PME 2024, a empresa opera de São Paulo com planos de
expansão para a América Latina. Mais em techflow.com.br.
```

## Variações

### Boilerplate para Releases
- Sempre no final, após "Sobre a [Marca]:"
- Inclua contato de imprensa

### Boilerplate para Propostas Comerciais
- Versão expandida + cases relevantes ao prospect

### Boilerplate para Redes Sociais
- Versão micro adaptada ao limite de caracteres
- Inclua link e CTA

### Checklist de Revisão
1. Dados atualizados? 2. Consistente com outros materiais?
3. Tem pelo menos uma prova? 4. Tom alinhado à marca?
