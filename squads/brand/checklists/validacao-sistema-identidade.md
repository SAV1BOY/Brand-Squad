# Checklist: Validação do Sistema de Identidade (Wheeler)

## Objetivo
Validar se o sistema de identidade de marca está completo e coerente segundo os princípios de Alina Wheeler (*Designing Brand Identity*). O sistema de identidade é o conjunto de elementos tangíveis que tornam a marca reconhecível e diferenciada em todos os pontos de contato.

---

## Critérios de Avaliação

### Elementos Fundamentais
- [ ] O logo/marca gráfica funciona em múltiplos tamanhos (do favicon ao outdoor) sem perder legibilidade
- [ ] Existe sistema de cores documentado com paleta primária e secundária, incluindo códigos (Pantone, CMYK, RGB, HEX)
- [ ] A tipografia está definida: fontes primária e secundária, hierarquia tipográfica, regras de uso
- [ ] Existe sistema de ícones, ilustrações ou grafismos complementares que ampliam o vocabulário visual

### Consistência entre Pontos de Contato
- [ ] A identidade foi testada/aplicada em pontos de contato digitais (site, app, redes sociais, e-mail)
- [ ] A identidade foi testada/aplicada em pontos de contato físicos/impressos (cartão, papelaria, embalagem, sinalização) quando aplicável
- [ ] A identidade funciona em fundo claro e escuro
- [ ] Existe versão monocromática funcional do logo e dos elementos visuais

### Identidade Verbal
- [ ] O tom de voz está documentado com características, princípios e exemplos ("assim sim" / "assim não")
- [ ] A arquitetura de mensagem está definida (tagline, proposta de valor, pilares de comunicação)
- [ ] Existe glossário de termos da marca (palavras que usa e palavras que evita)

### Documentação e Governança
- [ ] Existe um brand guidelines/brand book completo e atualizado
- [ ] Os assets da marca estão disponíveis em repositório centralizado e acessível (formatos corretos para cada uso)
- [ ] As regras de uso incorreto estão documentadas (o que NÃO fazer com a marca)
- [ ] Existe processo definido para aprovação de aplicações da marca em novos contextos

### Classificação

- **90–100%**: Sistema de identidade completo — marca consistente e profissionalmente implementável
- **70–89%**: Sistema funcional — elementos centrais presentes, lacunas menores a endereçar
- **50–69%**: Sistema incompleto — inconsistências prováveis na aplicação
- **Abaixo de 50%**: Sistema ausente ou fragmentado — identidade vulnerável a distorções

---

## Regras de Aplicação

1. Cada item é binário: **PASSA** (✓) ou **FALHA** (✗).
2. Os "Elementos Fundamentais" são pré-requisito: sem logo, cores e tipografia definidos, não há sistema de identidade.
3. A identidade verbal é frequentemente negligenciada mas igualmente importante — marcas que só definem o visual ficam inconsistentes na comunicação.
4. Score mínimo para aprovação: **75%**, com **100%** em Elementos Fundamentais.
