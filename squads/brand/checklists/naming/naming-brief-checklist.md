# Checklist de Brief de Naming
> Verifica se o brief de naming esta completo e contem todas as informacoes necessarias para o processo criativo.

## Quando Aplicar
Antes de iniciar qualquer processo de criacao de nomes, ao receber um pedido de naming de um cliente ou equipe interna.

## Criterios de Avaliacao

### Contexto Estrategico
- [ ] Posicionamento da marca descrito — Como a marca quer ser percebida no mercado
- [ ] Publico-alvo detalhado — Quem vai usar, comprar e interagir com o nome
- [ ] Cenario competitivo mapeado — Nomes dos principais concorrentes listados
- [ ] Categoria de atuacao definida — Em que mercado o nome vai operar

### Direcionamento Criativo
- [ ] Atributos desejados listados — O que o nome deve evocar (ex: inovacao, confianca, simplicidade)
- [ ] Atributos a evitar documentados — O que o nome nao deve sugerir
- [ ] Tipo de nome preferido indicado — Descritivo, sugestivo, abstrato, acronimo, fundador
- [ ] Idioma ou lingua definido — Em que idioma o nome deve funcionar primariamente
- [ ] Tom desejado descrito — Serio, divertido, sofisticado, acessivel, etc.

### Requisitos Tecnicos
- [ ] Necessidade de dominio especificada — Extensoes obrigatorias (.com, .com.br, etc.)
- [ ] Redes sociais prioritarias listadas — Plataformas onde o handle e essencial
- [ ] Restricoes legais conhecidas — Setores regulados ou termos proibidos
- [ ] Mercados geograficos de atuacao — Paises onde o nome deve funcionar

### Processo e Prazos
- [ ] Numero de opcoes esperado — Quantidade de nomes finalistas desejada
- [ ] Criterios de avaliacao definidos — Como as opcoes serao julgadas
- [ ] Decisores identificados — Quem tem voto na decisao final
- [ ] Cronograma aprovado — Prazos para cada etapa do processo de naming

## Scoring
| Nivel | Criterio | Acao |
|-------|----------|------|
| Verde (80%+) | 14+ criterios atendidos | Brief completo, iniciar processo criativo |
| Amarelo (60-79%) | 10-13 criterios atendidos | Completar informacoes antes de comecar |
| Vermelho (<60%) | Menos de 10 criterios atendidos | Brief insuficiente, sessao de briefing necessaria |

## Responsavel
Naming Specialist Agent — com input do Brand Strategist Agent e cliente.
