# Checklist: Screening Preliminar de Trademark

## Objetivo
Realizar triagem preliminar de registrabilidade de marca (trademark) para nomes candidatos. Este screening complementa o screening legal com foco específico em proteção de marca registrada nos mercados-alvo. NÃO substitui parecer jurídico especializado.

---

## Critérios de Avaliação

### Distintividade Intrínseca
- [ ] O nome NÃO é genérico para a categoria (termo que denomina o próprio produto/serviço — irregistrável)
- [ ] O nome NÃO é meramente descritivo (descreve característica, qualidade ou finalidade do produto — alto risco)
- [ ] O nome é pelo menos sugestivo (sugere indiretamente uma qualidade/benefício, exigindo imaginação do consumidor) ou, idealmente, arbitrário/inventado
- [ ] O nome não consiste exclusivamente em termo de uso comum na linguagem corrente

### Pesquisa de Anterioridade
- [ ] Busca realizada na base do INPI nas classes NCL relevantes — sem conflitos idênticos encontrados
- [ ] Busca fonética/visual realizada — sem conflitos por semelhança encontrados nas classes relevantes
- [ ] Busca em bases internacionais (USPTO, EUIPO, WIPO Madrid Monitor) realizada quando escopo inclui mercados externos
- [ ] Busca em registros de domínio e nomes empresariais (Junta Comercial/CNPJ) realizada

### Análise de Risco de Conflito
- [ ] Não existem marcas notoriamente conhecidas com nome idêntico ou similar (mesmo em classes diferentes — proteção ampla)
- [ ] Não existem marcas com registro prioritário (data anterior) em classes idênticas ou afins
- [ ] O nome não reproduz ou imita denominação de indicação geográfica protegida

### Viabilidade de Registro
- [ ] O nome não contém elementos irregistráveis isoladamente (bandeiras, brasões, termos oficiais) como elemento central
- [ ] O nome pode ser representado graficamente e tem potencial para registro como marca nominativa, mista ou figurativa
- [ ] Existe estratégia definida de classes NCL para o depósito (não apenas a classe principal, mas classes defensivas se aplicável)

### Classificação

- **90–100%**: Risco baixo — alta probabilidade de registrabilidade, prosseguir com depósito
- **70–89%**: Risco moderado — investigar pontos de atenção antes do depósito
- **50–69%**: Risco alto — considerar fortemente alternativas
- **Abaixo de 50%**: Risco proibitivo — descartar o nome ou reformular substancialmente

---

## Regras de Aplicação

1. Cada item é binário: **PASSA** (✓) ou **FALHA** (✗).
2. Falha em "Distintividade Intrínseca" item 1 (genérico) é eliminatória absoluta — nomes genéricos são irregistráveis.
3. Este screening é PRELIMINAR — um nome que passa aqui pode falhar na análise do examinador do INPI.
4. Sempre envolver advogado especialista em propriedade intelectual para parecer formal antes do depósito.
5. Score mínimo para prosseguir: **75%**.
