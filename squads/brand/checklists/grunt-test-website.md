# Teste Grunt para Websites
> Teste grunt para websites (Miller)

---

## Criterios

- [ ] **Oferta clara em 5 segundos:** Visitante entende o produto ou servico oferecido imediatamente
- [ ] **Beneficio principal visivel:** Como a marca melhora a vida do cliente esta evidente acima da dobra
- [ ] **CTA obvio:** Call-to-action principal visivel e sem ambiguidade na homepage
- [ ] **Header comunica valor:** Titulo principal articula proposta de valor, nao slogan vago
- [ ] **Cliente como heroi:** Linguagem do site fala sobre o cliente, nao sobre a empresa
- [ ] **Marca como guia:** Empresa demonstra empatia e autoridade sem ser protagonista
- [ ] **Problema articulado:** Dor ou desafio do visitante explicitamente mencionado no site
- [ ] **Plano de acao visivel:** Passos para o cliente seguir apresentados de forma simples
- [ ] **CTA transitorio disponivel:** Opcao secundaria para quem nao esta pronto (guia, newsletter)
- [ ] **Prova social visivel:** Depoimentos, logos de clientes ou numeros de impacto presentes
- [ ] **Mobile-friendly:** Experiencia em dispositivo movel e equivalente ao desktop
- [ ] **Navegacao simples:** Menu com no maximo 5-7 itens principais
