# Checklist de Disponibilidade de Handles
> Verifica a disponibilidade e adequacao de handles (nomes de usuario) em redes sociais e plataformas digitais.

## Quando Aplicar
Durante o processo de naming, ao lancar presenca em novas plataformas, ou ao auditar consistencia de handles existentes.

## Criterios de Avaliacao

### Plataformas Prioritarias
- [ ] Instagram verificado — Handle disponivel ou estrategia alternativa definida
- [ ] LinkedIn verificado — URL personalizada da pagina da empresa disponivel
- [ ] TikTok verificado — Handle disponivel na plataforma
- [ ] YouTube verificado — Handle e URL personalizada disponiveis
- [ ] X (Twitter) verificado — Handle disponivel na plataforma

### Plataformas Secundarias
- [ ] Facebook verificado — URL personalizada da pagina disponivel
- [ ] Pinterest verificado — Se relevante para o negocio
- [ ] GitHub verificado — Se marca de tecnologia, handle disponivel
- [ ] Threads verificado — Extensao do Instagram avaliada

### Consistencia
- [ ] Handle identico em todas as plataformas — Mesmo nome em todos os canais
- [ ] Se variacao necessaria, padrao definido — Regra clara para handles alternativos
- [ ] Variações defensivas reservadas — Typos e variacoes comuns registradas
- [ ] Documentacao de handles atualizada — Lista centralizada com login e responsavel

### Qualidade do Handle
- [ ] Curto e memoravel — Facil de digitar e comunicar
- [ ] Sem underscores ou pontos desnecessarios — Limpo e profissional
- [ ] Consistente com o dominio — Handle alinha com o nome do site
- [ ] Funciona como tag e mencao — @[handle] fica natural em conversas

### Protecao
- [ ] Handles registrados imediatamente — Nao esperar para garantir disponibilidade
- [ ] Contas antigas reivindicadas se necessario — Processo de recuperacao iniciado
- [ ] Monitoramento de impersonacao — Alertas para contas falsas ou similares
- [ ] Politica de handles documentada — Regras para criacao de handles em novas plataformas

## Scoring
| Nivel | Criterio | Acao |
|-------|----------|------|
| Verde (80%+) | 17+ criterios atendidos | Presenca digital consistente e protegida |
| Amarelo (60-79%) | 13-16 criterios atendidos | Resolver inconsistencias ou lacunas |
| Vermelho (<60%) | Menos de 13 criterios atendidos | Replanejar estrategia de handles |
