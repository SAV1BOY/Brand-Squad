# Checklist de Triagem de Dominio
> Avalia a qualidade e disponibilidade de dominios candidatos para novos projetos de marca.

## Quando Aplicar
Durante o processo de naming ao verificar dominios, ao lancar novos projetos digitais, ou ao avaliar aquisicao de dominios no mercado secundario.

## Criterios de Avaliacao

### Disponibilidade
- [ ] Dominio .com verificado — Status de disponibilidade ou preco de aquisicao levantado
- [ ] Dominio .com.br verificado — Disponibilidade no Registro.br consultada
- [ ] Extensoes alternativas avaliadas — .co, .io, .app, .tech e outras relevantes verificadas
- [ ] Preco de aquisicao aceitavel — Se nao disponivel, custo de compra dentro do orcamento

### Qualidade do Dominio
- [ ] Comprimento adequado — Idealmente ate 15 caracteres sem a extensao
- [ ] Sem hifens — Dominios com hifen evitados por serem menos memoraveis
- [ ] Sem numeros — A menos que o numero seja parte essencial do nome da marca
- [ ] Soletração inequivoca — Nenhuma confusao ao ditar o dominio verbalmente
- [ ] Nao forma palavras indesejadas — Leitura concatenada nao gera interpretacoes negativas

### Historico e Seguranca
- [ ] Historico do dominio verificado — Wayback Machine consultada para uso anterior
- [ ] Blacklists verificadas — Dominio nao esta em listas de spam ou malware
- [ ] WHOIS anterior limpo — Registro anterior nao e problematico
- [ ] Backlinks anteriores avaliados — Links para o dominio nao sao toxicos

### Alinhamento com a Marca
- [ ] Corresponde ao nome da marca — Dominio identico ou variacao muito proxima
- [ ] Memoravel e digitavel — Facil de lembrar e digitar corretamente
- [ ] Funciona como URL completa — "www.[dominio]" soa profissional quando falado
- [ ] Compativel com estrategia de email — [nome]@[dominio] funciona bem

## Scoring
| Nivel | Criterio | Acao |
|-------|----------|------|
| Verde (80%+) | 14+ criterios atendidos | Dominio aprovado para registro |
| Amarelo (60-79%) | 10-13 criterios atendidos | Avaliar trade-offs antes de prosseguir |
| Vermelho (<60%) | Menos de 10 criterios atendidos | Buscar dominio alternativo |

Domain Specialist Agent — com aprovacao do Naming Specialist Agent.
