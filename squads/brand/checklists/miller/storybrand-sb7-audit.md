# Auditoria StoryBrand SB7 de Miller
> Avalia a comunicacao de marca usando o framework SB7 de Donald Miller — Building a StoryBrand.

## Quando Aplicar
Ao criar ou revisar mensagens de marca, ao redesenhar website, ou quando a comunicacao nao gera conversao.

## Criterios de Avaliacao

### 1. Personagem (Heroi = Cliente)
- [ ] Cliente como heroi da historia — Marca nao se posiciona como protagonista
- [ ] Desejo do cliente articulado — O que o cliente quer esta claro e especifico
- [ ] Desejo e simples e relevante — Focado em uma necessidade principal, nao multiplas

### 2. Problema
- [ ] Problema externo identificado — Problema tangivel e visivel que o cliente enfrenta
- [ ] Problema interno identificado — Frustracao emocional causada pelo problema externo
- [ ] Problema filosofico articulado — Por que e injusto que o cliente tenha esse problema
- [ ] Vilao nomeado — A fonte do problema (nao uma pessoa, mas uma forca ou situacao)

### 3. Guia (Marca)
- [ ] Marca como guia, nao heroi — Marca se posiciona como mentora do cliente
- [ ] Empatia demonstrada — Marca mostra que entende a dor do cliente
- [ ] Autoridade estabelecida — Credenciais, resultados ou depoimentos que geram confianca

### 4. Plano
- [ ] Plano de 3-4 passos criado — Caminho simples que o cliente deve seguir
- [ ] Passos sao claros e simples — Qualquer pessoa entende o que fazer
- [ ] Acordo ou garantia presente — Algo que reduz o risco percebido pelo cliente

### 5-6. Chamada para Acao
- [ ] CTA direto presente — Botao ou frase de acao principal clara (ex: "Compre agora")
- [ ] CTA transitorio presente — Opcao de menor compromisso (ex: "Baixe o guia gratuito")
- [ ] CTAs visiveis e repetidos — Presentes em multiplos pontos da comunicacao

### 7. Resultado
- [ ] Sucesso descrito — Como a vida do cliente melhora apos usar a marca
- [ ] Fracasso descrito — O que acontece se o cliente nao agir
- [ ] Transformacao articulada — De quem o cliente e para quem ele se torna

## Scoring
| Nivel | Criterio | Acao |
|-------|----------|------|
| Verde (80%+) | 15+ criterios atendidos | Comunicacao StoryBrand completa e eficaz |
| Amarelo (60-79%) | 11-14 criterios atendidos | Reforcar elementos faltantes do SB7 |
| Vermelho (<60%) | Menos de 11 criterios atendidos | Refazer comunicacao usando framework SB7 completo |
