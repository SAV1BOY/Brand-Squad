# Due Diligence de Historico de Dominio
> Due diligence de historico de dominio

---

## Criterios

- [ ] **Wayback Machine consultada:** Historico de conteudo do dominio analisado via archive.org
- [ ] **Conteudo anterior compativel:** Uso previo do dominio nao conflita com valores da marca
- [ ] **Sem historico ofensivo:** Dominio nunca hospedou conteudo adulto, ilegal ou ofensivo
- [ ] **Sem associacao com fraude:** Dominio nao foi usado para phishing, spam ou golpes
- [ ] **Backlink profile analisado:** Links apontando para o dominio verificados quanto a qualidade
- [ ] **Sem penalidades de buscadores:** Dominio nao esta em blacklist de motores de busca
- [ ] **Domain authority verificada:** Metricas de autoridade do dominio foram consultadas
- [ ] **Spam score avaliado:** Risco de spam do dominio esta dentro de niveis aceitaveis
- [ ] **Blacklists de seguranca consultadas:** Dominio verificado em listas de malware e phishing
- [ ] **Reputacao de email checada:** Dominio nao esta em blacklists de email (Spamhaus, etc.)
- [ ] **Proprietario anterior identificado:** Historico de ownership do dominio esta documentado
- [ ] **Sem disputas legais pendentes:** Nenhuma acao judicial envolvendo o dominio em andamento

---

| Faixa | Resultado |
|-------|-----------|

| 70-89% | Bom |

| < 50% | Critico |
