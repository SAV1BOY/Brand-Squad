# Criterios de Qualidade para Brand Books
> Criterios de qualidade para brand books

---

## Criterios

- [ ] **Fundamentos estrategicos:** Proposito, valores, posicionamento e personalidade documentados
- [ ] **Sistema visual completo:** Logo, variacoes, cores, tipografia, imagistica e grid incluidos
- [ ] **Sistema verbal completo:** Tom de voz, mensagens-chave, vocabulario e exemplos de copy
- [ ] **Regras de aplicacao:** Do e dont claros para cada elemento visual e verbal
- [ ] **Especificacoes tecnicas:** Codigos de cor (HEX, RGB, CMYK, Pantone) e tamanhos minimos
- [ ] **Templates fornecidos:** Arquivos editaveis para aplicacoes mais comuns disponiveis
- [ ] **Exemplos reais incluidos:** Mockups e aplicacoes que ilustram uso correto
- [ ] **Linguagem acessivel:** Manual compreensivel por nao-designers e nao-marketeiros
- [ ] **Navegacao intuitiva:** Indice claro e secoes bem organizadas para consulta rapida
- [ ] **Versionamento controlado:** Numero de versao e data de atualizacao visiveis
- [ ] **Responsavel definido:** Pessoa ou equipe dona do brand book claramente identificada
- [ ] **Processo de excecoes:** Canal claro para solicitar desvios das regras estabelecido

## Scoring

| Faixa | Resultado |
|-------|-----------|
| 90-100% | Excelente |
| 70-89% | Bom |
| 50-69% | Necessita melhorias |
| < 50% | Critico |
