# Paleta de Cores
> Template para documentar o sistema de cores da marca com especificacoes tecnicas completas.

## Instrucoes de Uso
Preencha apos a finalizacao da identidade visual. Inclua todas as especificacoes tecnicas
necessarias para reproducao fiel em qualquer meio. Forneca regras claras de combinacao
e proporcao. Distribua para designers, desenvolvedores e fornecedores graficos.

## Checklist de Qualidade

- [ ] Combinacoes permitidas e proibidas estao documentadas
- [ ] Testes de acessibilidade WCAG foram realizados
- [ ] Regras de reproducao para impressao estao incluidas
