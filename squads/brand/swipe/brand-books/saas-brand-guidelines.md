# Brand Guidelines de SaaS — Referências

> Como marcas SaaS lideres documentam e implementam suas identidades de marca.

## Padroes da Industria SaaS

Marcas SaaS tendem a ter guidelines que priorizam: escalabilidade digital, component-based design, tom de voz para produto (microcopy) e flexibilidade para crescimento rapido.

## Referencias Detalhadas

### Figma Brand
- Cor primaria vibrante + sistema de gradientes
- Typography system com font propria
- Motion guidelines integradas
- Guidelines para community-generated content

### Notion
- Minimalismo radical — preto, branco, emojis
- Tipografia como elemento de personalidade (serif em tech)
- Flexibilidade proposital — a "falta" de regra e a regra

### Linear
- Identidade developer-first — dark mode como padrao
- Gradientes como sistema de diferenciacão de features
- Precision em every pixel — engenharia visual

### Stripe
- Gradientes icônicos que definiram uma tendencia
- Copy tecnico com clareza excepcional
- Sistema visual que escala de docs a dashboards

### HubSpot
- Laranja como cor de categoria — possuem completamente
- Personality guidelines detalhadas
- Fotografia com estilo especifico documentado

## Licoes para Guidelines SaaS

1. Incluir guidelines de produto (UI/UX) alem de marketing
2. Documentar microcopy e UX writing
3. Dark mode e responsive sao obrigatorios
4. Motion e animacao devem ser documentados
5. Developer docs devem seguir brand voice
