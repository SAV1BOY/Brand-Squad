# FAQ — Perguntas Frequentes

> Respostas rápidas para as dúvidas mais comuns sobre o Brand Squad.

## Geral

### O que é o Brand Squad?
Um sistema de agentes especializados em branding com ferramentas, frameworks, templates e processos para criar e gerenciar marcas profissionalmente.

### Para quem é o Brand Squad?
Para qualquer pessoa ou equipe que precise construir, refinar ou gerenciar uma marca — de startups a empresas estabelecidas.

### Preciso usar tudo?
Não. Use o que é relevante para seu projeto. Comece por `getting-started.md` e `projects/` para encontrar o caminho certo.

## Uso

### Por onde começo um novo projeto de marca?
1. Leia `getting-started.md`
2. Identifique seu tipo de projeto em `projects/`
3. Siga as fases e use os recursos indicados

### Como escolho o framework certo?
Consulte `framework-selection-guide.md`. A escolha depende do objetivo, tipo de empresa e fase do projeto.

### Posso usar mais de um framework?
Sim, é recomendado. Use 2-3 frameworks complementares. Frameworks são ferramentas, não religiões.

### Os templates são obrigatórios?
São fortemente recomendados. Garantem consistência e completude. Mas podem ser adaptados ao contexto.

## Conteúdo

### Por que tudo está em português?
O squad foi criado para o mercado brasileiro. Termos técnicos em inglês são mantidos quando não há tradução estabelecida.

### Posso contribuir com novos conteúdos?
Sim. Siga o `style-guide.md` e `naming-conventions.md`. Registre no `changelog.md`.

### Com que frequência o conteúdo é atualizado?
Revisão geral semestral. Atualizações pontuais conforme necessidade. Veja `changelog.md` para histórico.

## Processos

### Quem aprova materiais de marca?
Depende do nível. Veja `brand-governance-policy.md` para os 4 níveis de aprovação.

### Como faço uma auditoria de marca?
Siga `projects/brand-audit-project.md` e use `lib/utilities/brand-audit-rubric.md`.

### Como lido com uma crise de marca?
Siga `projects/brand-crisis-response-project.md` imediatamente. Primeiras 2 horas são críticas.

### Como integro com outros squads?
Consulte `cross-squad-integration-guide.md` para protocolos de colaboração.

## Problemas Comuns

### Não encontro o recurso que preciso
Verifique `squad-overview.md` para a estrutura completa. Use busca por palavras-chave nos arquivos.

### Frameworks se contradizem
Normal. Frameworks são perspectivas, não verdades absolutas. Use o julgamento para selecionar o mais adequado ao contexto.
