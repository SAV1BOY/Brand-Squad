# Guia de Workflows

> Como os fluxos de trabalho do Brand Squad funcionam e como utilizá-los.

## O Que São Workflows

Workflows são sequências estruturadas de tarefas executadas por agentes em ordem definida. Cada workflow tem inputs, etapas, quality gates e outputs claros.

## Workflows Disponíveis

### Brand Discovery
- **Input**: Brief do cliente/stakeholder
- **Etapas**: Pesquisa → Entrevistas → Análise → Diagnóstico
- **Output**: Relatório de discovery com insights e recomendações
- **Agente líder**: Research Analyst

### Brand Strategy
- **Input**: Relatório de discovery
- **Etapas**: Posicionamento → Plataforma → Arquitetura → Validação
- **Output**: Plataforma de marca aprovada
- **Agente líder**: Brand Strategist

### Naming Workflow
- **Input**: Brief de naming + plataforma de marca
- **Etapas**: Geração → Triagem → Validação → Teste → Decisão
- **Output**: Nome aprovado e registrado
- **Agente líder**: Naming Specialist

### Identity Development
- **Input**: Plataforma de marca + nome aprovado
- **Etapas**: Verbal → Visual briefing → Desenvolvimento → Guidelines
- **Output**: Brand guidelines completo
- **Agentes**: Voice Architect + Visual Director

### Brand Launch
- **Input**: Guidelines + materiais prontos
- **Etapas**: Mapeamento → Produção → Interno → Externo → Monitoramento
- **Output**: Marca lançada em todos os touchpoints
- **Agente líder**: Brand Strategist

## Regras dos Workflows

1. Cada etapa deve ser concluída antes da próxima iniciar
2. Quality gates validam a transição entre etapas
3. Stakeholders aprovam ao final de cada workflow
4. Documentação é obrigatória em cada etapa
5. Voltar etapas é permitido, mas documentado

## Como Iniciar um Workflow

1. Identifique o workflow correto para seu projeto
2. Verifique se os inputs estão disponíveis
3. Designe o agente líder
4. Siga as etapas na ordem
5. Valide cada quality gate antes de avançar
