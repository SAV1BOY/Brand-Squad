# Guia de Uso de Checklists

> Como usar os checklists do Brand Squad para garantir qualidade em cada etapa.

## Propósito

Checklists são quality gates que garantem que nenhum passo crítico seja esquecido. Não substituem julgamento — complementam-no.

## Organização dos Checklists

Checklists estão em `checklists/` organizados por autor/metodologia:
- **aaker/**: Checklists baseados em David Aaker
- **keller/**: Checklists baseados em Kevin Lane Keller
- **sharp/**: Checklists baseados em Byron Sharp
- **wheeler/**: Checklists baseados em Alina Wheeler
- **naming/**: Checklists específicos de naming
- **domains/**: Verificação de domínios
- E outros por autor/tema

## Como Usar

### Antes de Iniciar
1. Identifique a fase do projeto
2. Selecione o checklist correspondente
3. Leia todos os itens antes de começar o trabalho

### Durante a Execução
1. Marque itens conforme são completados
2. Documente exceções ou itens não aplicáveis
3. Não pule itens — avalie cada um conscientemente

### Ao Finalizar
1. Todos os itens devem estar marcados ou justificados
2. Itens críticos (marcados com !) nunca podem ser pulados
3. Checklist concluído = aprovação para avançar

## Tipos de Checklist

- **Verificação**: Itens sim/não para validar completude
- **Avaliação**: Itens com pontuação para medir qualidade
- **Processo**: Itens sequenciais que devem ser seguidos em ordem

## Boas Práticas

1. Use checklists de DIFERENTES autores para mesma fase (perspectivas complementares)
2. Customize adicionando itens específicos do projeto
3. Revise checklists após cada projeto (melhoria contínua)
4. Mantenha registro de checklists concluídos por projeto
