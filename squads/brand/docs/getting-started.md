# Primeiros Passos com o Brand Squad

> Guia rápido para começar a usar o Brand Squad em seus projetos de marca.

## O Que É o Brand Squad

O Brand Squad é um sistema de agentes especializados em branding que trabalham juntos para criar, gerenciar e evoluir marcas. Cada agente tem uma expertise específica e todos seguem frameworks, templates e padrões documentados.

## Como Começar

### 1. Entenda a Estrutura
- **Agentes**: Especialistas com papéis definidos (veja `agent-roles-guide.md`)
- **Frameworks**: Metodologias de referência (Aaker, Keller, Sharp, etc.)
- **Templates**: Modelos prontos para documentos de marca
- **Checklists**: Verificações de qualidade por etapa
- **Phrases**: Biblioteca de vocabulário e fórmulas
- **Lib**: Componentes, padrões e utilitários reutilizáveis

### 2. Identifique Seu Projeto
- Nova marca? → `projects/new-brand-project.md`
- Rebrand? → `projects/rebrand-project.md`
- Naming? → `projects/naming-project.md`
- Auditoria? → `projects/brand-audit-project.md`
- Consulte `projects/` para todos os tipos de projeto

### 3. Selecione os Recursos
- Escolha o framework adequado → `framework-selection-guide.md`
- Use templates para documentos → `template-usage-guide.md`
- Valide com checklists → `checklist-usage-guide.md`
- Busque inspiração → `swipe-file-guide.md`

### 4. Execute e Valide
- Siga as fases do projeto escolhido
- Use quality gates para validar cada entrega
- Consulte a biblioteca de frases para comunicação
- Aplique padrões da lib para consistência

## Fluxo Típico

```
Discovery → Estratégia → Criação → Validação → Guidelines → Lançamento
```
