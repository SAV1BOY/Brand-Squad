# Guia de Estilo do Brand Squad

> Padrões de escrita e formatação para todos os documentos produzidos pelo squad.

## Idioma

- Todo conteúdo em português brasileiro (pt-BR)
- Acentuação obrigatória e correta
- Termos técnicos em inglês são aceitos quando não há tradução estabelecida
- Na primeira menção, inclua tradução entre parênteses se necessário

## Formatação de Documentos

### Estrutura Padrão
```
# Título Principal
> Descrição em uma linha
## Seção
### Subseção
- Itens de lista
```

### Hierarquia de Títulos
- `#` — Título do documento (1 por arquivo)
- `##` — Seções principais
- `###` — Subseções
- `####` — Raramente usado, preferir listas

### Listas
- Use `-` para listas não ordenadas
- Use `1.` para listas ordenadas (quando sequência importa)
- Máximo 2 níveis de aninhamento

## Escrita

### Tom
- Direto e prático — sem enrolação
- Profissional sem ser formal demais
- Confiante sem ser arrogante
- Instrutivo sem ser condescendente

### Regras
- Frases curtas (máximo 25 palavras ideal)
- Parágrafos curtos (máximo 3-4 linhas)
- Voz ativa sobre passiva
- Específico sobre genérico
- Verbos de ação no imperativo para instruções

### Convenções
- Nomes de marcas: capitalização original (iPhone, LinkedIn)
- Nomes de frameworks: com autor (Keller CBBE, Aaker Brand Equity)
- Referências a arquivos: formato `código` com path relativo
- Números: por extenso até dez, numeral a partir de 11
- Porcentagens: sempre numeral + % (5%, 100%)

## Versionamento

- Todo documento deve ter data de última atualização
- Mudanças significativas documentadas no changelog
- Versões anteriores preservadas no histórico git
