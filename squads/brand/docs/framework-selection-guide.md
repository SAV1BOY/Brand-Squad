# Guia de Seleção de Framework

> Como escolher o framework de branding mais adequado para cada situação.

## Visão Geral

Cada framework oferece uma lente diferente para problemas de marca. Não existe "melhor" framework — existe o mais adequado para o contexto.

## Matriz de Seleção

### Por Objetivo

| Objetivo | Framework Recomendado |
|----------|----------------------|
| Posicionamento | Ries & Trout, Keller |
| Brand equity | Aaker, Keller (CBBE) |
| Identidade de marca | Kapferer (Prisma) |
| Naming | Processo proprietário + Neumeier |
| Diferenciação | Sharp (How Brands Grow), Neumeier |
| Arquitetura | Aaker (Brand Portfolio) |
| Storytelling | Miller (StoryBrand) |
| Personalidade | Arquétipos (Jung/Mark & Pearson) |
| Guidelines | Wheeler (Designing Brand Identity) |
| Mensuração | Keller (CBBE), Young & Rubicam (BAV) |

### Por Tipo de Empresa

| Tipo | Frameworks Prioritários |
|------|------------------------|
| Startup early-stage | Miller (StoryBrand) + Ries (posicionamento) |
| Scale-up | Aaker (equity) + Sharp (crescimento) |
| Empresa estabelecida | Keller (CBBE) + Kapferer (identidade) |
| Rebrand | Kapferer + Wheeler + Neumeier |

### Por Fase do Projeto

| Fase | Framework |
|------|-----------|
| Discovery | Sharp (categorias), Keller (pesquisa) |
| Estratégia | Ries, Aaker, Kapferer |
| Criação | Miller, Neumeier, Arquétipos |
| Implementação | Wheeler, Sharp (ativos) |
| Mensuração | Keller, Aaker, Sharp |

## Combinações Comuns

1. **Nova marca B2B**: Ries (posicionamento) + Keller (equity) + Miller (narrativa)
2. **Nova marca B2C**: Sharp (saliência) + Arquétipos + Neumeier (diferenciação)
3. **Rebrand**: Kapferer (identidade) + Wheeler (implementação)
4. **Extensão de marca**: Aaker (arquitetura) + Keller (fit)

## Regra de Ouro

Use 2-3 frameworks complementares, nunca um sozinho. Frameworks são ferramentas, não religiões.
