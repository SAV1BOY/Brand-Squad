# Padrões de Revisão de Marca

> Critérios e processos para revisar e aprovar materiais e decisões de marca.

## Critérios de Revisão

### Alinhamento Estratégico
- [ ] Consistente com o posicionamento da marca?
- [ ] Reforça (não contradiz) os valores da marca?
- [ ] Adequado para o público-alvo?
- [ ] Alinhado com os pilares de mensagem?

### Identidade Visual
- [ ] Logo aplicado corretamente (tamanho, espaço, cor)?
- [ ] Cores dentro da paleta aprovada?
- [ ] Tipografia conforme guidelines?
- [ ] Estilo fotográfico/ilustrativo consistente?
- [ ] Hierarquia visual clara?

### Identidade Verbal
- [ ] Tom de voz consistente com guidelines?
- [ ] Sem palavras proibidas (ver tone-words-forbidden)?
- [ ] Gramática e ortografia revisadas?
- [ ] Messaging alinhado aos pilares?
- [ ] Boilerplate atualizado (se aplicável)?

### Qualidade Geral
- [ ] Sem erros factuais (dados, nomes, datas)?
- [ ] Arquivos em formato e resolução corretos?
- [ ] Testado em diferentes tamanhos/dispositivos?
- [ ] Acessível (contraste, legibilidade)?

## Processo de Revisão

### Revisão Simples (1 dia)
- 1 revisor (Brand Manager)
- Para: posts sociais, emails, materiais internos

### Revisão Padrão (3 dias)
- 2 revisores (Brand Manager + Especialista)
- Para: campanhas, landing pages, apresentações externas

### Revisão Estratégica (5 dias)
- 3+ revisores (Brand Strategist + especialistas + stakeholder)
- Para: rebrands, novos produtos, parcerias estratégicas

## Feedback

- Seja específico: "A cor do CTA não é a primária" (não "não gostei")
- Referencie guidelines: cite a página/seção relevante
- Priorize: indique o que é blocker vs nice-to-have
- Proponha solução junto com o problema
