# Changelog do Brand Squad

> Registro de todas as alterações significativas no Brand Squad.

## Formato

Cada entrada segue o formato:
```
### [Data] — [Tipo de mudança]
- Descrição da mudança
- Arquivos afetados
- Motivação (se relevante)
```

## Tipos de Mudança
- **Adição**: Novos arquivos ou seções
- **Atualização**: Modificação de conteúdo existente
- **Correção**: Fix de erros ou inconsistências
- **Remoção**: Conteúdo removido ou arquivado
- **Reestruturação**: Mudança de organização ou nomenclatura
