# Guia de Uso de Templates

> Como encontrar, usar e customizar templates do Brand Squad.

## Onde Encontrar Templates

Templates estão organizados em `templates/` por categoria:
- Plataforma de marca
- Briefings
- Documentos estratégicos
- Apresentações
- Guidelines

## Como Usar

### 1. Selecione o Template
- Identifique o tipo de documento que precisa criar
- Encontre o template correspondente na pasta
- Leia a descrição no topo do arquivo

### 2. Preencha os Campos
- Campos entre `[colchetes]` devem ser substituídos
- Seções marcadas com `(opcional)` podem ser removidas
- Exemplos em itálico são referência — substitua com dados reais

### 3. Adapte ao Contexto
- Templates são pontos de partida, não contratos rígidos
- Adicione seções relevantes para o projeto específico
- Remova seções que não se aplicam
- Mantenha a estrutura e formatação padrão

### 4. Valide
- Use o checklist correspondente para validar o documento
- Peça revisão de pelo menos 1 outro agente
- Verifique consistência com outros documentos do projeto

## Boas Práticas

1. **Não comece do zero**: Sempre parta de um template
2. **Mantenha o formato**: Hierarquia de títulos e organização
3. **Cite fontes**: Se usar dados ou referências externas
4. **Versione**: Inclua data e versão no documento
5. **Armazene**: Salve documentos preenchidos na pasta do projeto

## Templates Mais Usados

- Plataforma de marca (estratégia central)
- Brand brief (briefing para parceiros)
- Messaging framework (pilares de mensagem)
- Competitive analysis (análise competitiva)
- Brand guidelines (manual de marca)

## Contribuindo com Novos Templates

Se identificar necessidade de novo template:
1. Baseie-se em templates existentes para manter padrão
2. Inclua descrição, instruções e exemplo
3. Adicione ao diretório correto
4. Atualize o changelog
