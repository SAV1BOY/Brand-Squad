# Guia de Swipe Files

> Como usar a coleção de referências inspiracionais do Brand Squad.

## O Que São Swipe Files

Swipe files são coleções curadas de exemplos reais de branding excelente. Servem como referência e inspiração — nunca para cópia direta.

## Organização

Os swipe files estão em `swipe/` organizados por tipo:
- **identity-systems/**: Sistemas de identidade visual completos
- **brand-books/**: Exemplos de brand books e guidelines
- **positioning/**: Casos de posicionamento estratégico
- **naming/**: Exemplos de nomes bem-sucedidos
- **brand-experience/**: Experiências de marca memoráveis
- **manifestos/**: Manifestos e textos de marca
- **campaigns/**: Campanhas de marca (não performance)
- **taglines/**: Coleção de taglines por categoria

## Como Usar

### Para Inspiração
1. Navegue pela categoria relevante ao seu projeto
2. Analise O QUE funciona e POR QUE funciona
3. Extraia princípios, não execuções específicas
4. Documente insights para referência

### Para Benchmarking
1. Selecione 5-8 exemplos da mesma categoria
2. Analise padrões comuns (o que todos fazem)
3. Identifique destaques (o que poucos fazem excepcionalmente)
4. Use como referência para posicionar seu projeto

### Para Apresentações
1. Use exemplos como precedentes para recomendar abordagens
2. Mostre "antes e depois" de rebrands como argumento
3. Cite cases de sucesso para validar estratégias

## Regras de Uso

1. **Inspire-se, não copie**: Extraia princípios, crie execuções originais
2. **Contextualize**: O que funciona para uma marca pode não funcionar para outra
3. **Atualize**: Contribua com novos exemplos quando encontrar
4. **Credite**: Sempre atribua exemplos às marcas originais
5. **Diversifique**: Não se limite a marcas americanas — busque referências brasileiras e globais
