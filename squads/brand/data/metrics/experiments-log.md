# Log de Experimentos de Marca

> Registro de todos os testes e experimentos realizados para otimizar estrategia de marca.

## Formato do Registro

```
## Experimento: [Titulo]
**Data**: YYYY-MM-DD
**Hipotese**: Se [acao], entao [resultado esperado], porque [razao]
**Metrica Principal**: [KPI que sera medido]
**Duracao**: [periodo do teste]
**Resultado**: [o que aconteceu]
**Aprendizado**: [insight gerado]
**Acao Seguinte**: [o que fazer com base no resultado]
```

## Categorias de Experimentos

### Messaging
- A/B test de headlines e propostas de valor
- Teste de diferentes frameworks de mensagem (StoryBrand vs. JTBD)
- Variações de tom de voz por canal

### Visual
- Teste de cores em CTAs e elementos primarios
- Variações de layout de landing page
- Teste de estilos de fotografia/ilustracao

### Posicionamento
- Teste de diferentes angulos de posicionamento
- Variações de proposta de valor por segmento
- Teste de pricing e percepcao de valor

### Canal
- Teste de novos canais de comunicacao
- Variacoes de frequencia de comunicacao
- Teste de formatos de conteudo

## Principios de Experimentacao

1. Uma variavel por teste — isolar causa e efeito
2. Tamanho de amostra suficiente para significancia
3. Documentar TUDO — inclusive testes que "falharam"
4. Compartilhar aprendizados com toda a equipe
5. Converter aprendizados em mudancas de guidelines/processo
